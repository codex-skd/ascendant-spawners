<h2>v0.0.0-beta.1 - Port to Minecraft 1.21.1</h2>

<p>First beta of Ascendant Spawners for <strong>Minecraft 1.21.1 / NeoForge 21.1.249</strong> (Java 21). Same spawner toolkit as the 26.2 build.</p>

<h3>About this build</h3>
<ul>
<li><strong>Re-fork, not a back-port</strong>: rebuilt from the upstream <a href="https://www.curseforge.com/minecraft/mc-mods/apothic-spawners">Apothic Spawners</a> 1.21 sources (1.4.0, Shadows_of_Fire / Stormraven Studios, MIT), rebranded to the Ascendant Spawners identity.</li>
<li><strong>Feature parity with 26.2</strong>: the Capturing enchantment (silk-touch spawners), the full spawner stat-modification recipe list (with <code>_inverse</code> recipes), the Shift / Jade stat tooltip, the advancement tab, and JEI + Jade compat.</li>
<li><strong>Dependencies</strong>: Common Toolkit (required, our fork of Placebo). Ascendant Equipment is optional (no 1.21.1 build yet). JEI and Jade are optional compat.</li>
</ul>

<h3>Notes</h3>
<blockquote>Install Common Toolkit on both client and server before this mod. MIT licensed (upstream copyright kept in <code>LICENSE</code>); all in-game assets are original to this project.</blockquote>
