<h2>v0.0.0-beta.6 - Dependency version range cleanup</h2>

<p>Replaces the temporary <code>[0.0.0-alpha,)</code> version-range workaround introduced in beta.5 with precise beta floors.</p>

<h3>Fix</h3>
<ul>
<li><code>common_toolkit</code>: <code>[0.0.0-alpha,) &rarr; [0.0.0-beta.1,)</code>.</li>
<li><code>ascendant_equipment</code> (optional): <code>[0.0.0-alpha,) &rarr; [0.0.0-beta.4,)</code>.</li>
</ul>
<p>The <code>[0.0.0-alpha,)</code> range worked (Maven-style comparison ranks <code>alpha</code> below <code>beta</code>, so it accepted any beta build), but it was imprecise and misleading. The lower bound now reflects the real current beta of each dependency.</p>

<blockquote>Early development build. Textures are placeholders — final art is a separate, non-blocking follow-up. Ascendant Equipment is currently an optional dependency until this mod integrates with it; it will become required then.</blockquote>
