<h2>v0.0.0-beta.10 - Security & Stability Improvements</h2>

<h3>Changes</h3>
<ul>
<li><strong>Security Hardening</strong>: Added null-safety checks in <code>SpawnerJEIPlugin</code> to prevent potential <code>NullPointerException</code> when accessing client level context. All optional Minecraft API calls now properly guard against null values.</li>

<li><strong>Build System Fixes</strong>: Fixed critical mixin detection logic in <code>build.gradle</code>. Previous versions had a broken file discovery algorithm that prevented mixins from being properly registered in the compiled JAR. All three mixins (<code>BlocksMixin</code>, <code>ItemsMixin</code>, <code>ItemStackMixin</code>) are now correctly detected and compiled.
<blockquote>
Technical: The build process was constructing source paths incorrectly on Windows, causing <code>fileTree()</code> to fail finding Java files. Rewrote path construction to use Gradle's <code>file()</code> API and replaced fragile string parsing with direct <code>listFiles()</code> filtering.
</blockquote>
</li>

<li><strong>Documentation</strong>: Added inline comments explaining future migration path for NeoForge 26.2+ updates. Updated gradle.properties with notes on version compatibility.</li>

<li><strong>Code Quality</strong>: Full compilation verified against NeoForge 26.2.0.37-beta with zero errors or critical warnings.</li>
</ul>
