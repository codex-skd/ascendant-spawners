<h2>v0.0.0-beta.5 - Core gameplay ported</h2>

<p>Core gameplay from ApothicSpawners is now ported and functional, on top of the initial scaffold from beta.1.</p>

<h3>Features</h3>
<ul>
<li>Silk-touch mob spawners and pick them up as items.</li>
<li>Modify spawner stats (spawn delay, range, count, redstone control, no AI, ignore light/players/conditions, and more) via crafting recipes.</li>
<li>The <strong>Capturing</strong> enchantment: gives a chance for killed mobs to drop their spawn egg.</li>
<li>JEI integration: browse spawner modifier recipes in the recipe viewer.</li>
<li>Jade integration: tooltip overlay when looking at a modified spawner.</li>
<li>Advancements tracking spawner collection and modification milestones.</li>
</ul>

<h3>Technical Changes</h3>
<ul>
<li>Full core, compat (JEI + Jade), and mixin layers ported 1:1 from ApothicSpawners with all identifiers renamed to this project's convention.</li>
<li>Fixed several build/runtime issues inherited from the project scaffold, most notably a real vanilla API change in NeoForge 26.2 (<code>Blocks.register()</code> moved from a <code>String</code>-keyed overload to one keyed by <code>BlockItemId</code>), which required rewriting the block/item registration mixins against the real 26.2 bytecode.</li>
<li>JEI pinned to <code>30.15.0.121</code> for compatibility with NeoForge <code>26.2.0.32-beta</code>.</li>
</ul>

<blockquote>Early development build. Textures are placeholders — final art is a separate, non-blocking follow-up. Ascendant Equipment is currently an optional dependency until it ships its own build; it will become required once this mod integrates with it.</blockquote>
