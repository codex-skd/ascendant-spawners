<h2>v0.0.0-beta.7 - Fix load-order cycle crash</h2>

<p>Fixes a startup crash caused by a mutual <code>ordering="AFTER"</code> constraint between Ascendant Spawners and Ascendant Equipment.</p>

<h3>Fix</h3>
<ul>
<li>The optional <code>ascendant_equipment</code> dependency used <code>ordering="AFTER"</code>, but <code>ascendant_equipment</code> also declares this mod with <code>ordering="AFTER"</code>. The reciprocal ordering made a cycle that NeoForge cannot topologically sort, failing mod discovery (<code>Mod Sorting failed. Detected Cycles</code>) and preventing the client from starting.</li>
<li>Changed to <code>ordering="NONE"</code> so the dependency remains optional without imposing an ordering edge.</li>
<li>Version floor for the optional <code>ascendant_equipment</code> dependency raised to <code>[0.0.0-beta.5,)</code>.</li>
</ul>

<blockquote>Early development build. Textures are placeholders — final art is a separate, non-blocking follow-up. Ascendant Equipment is currently an optional dependency until this mod integrates with it; it will become required then (without a reciprocal ordering).</blockquote>
