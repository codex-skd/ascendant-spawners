# Ascendant Spawners

Ascendant Spawners is a Minecraft 26.2 (NeoForge) mod.

> This mod is a port of [ApothicSpawners](https://www.curseforge.com/minecraft/mc-mods/apothic-spawners) by Shadows_of_Fire, ported from NeoForge 26.1.2 to NeoForge 26.2. Not affiliated with or endorsed by the original author. It is the spawner module of [Ascendant Equipment](../../../ascendant_equipment/neoforge/26.2) (our port of Apotheosis), and depends on [Common Toolkit](../../../common_toolkit/neoforge/26.2) (our port of Placebo). See [docs/ROADMAP_ASCENDANT_SPAWNERS.md](docs/ROADMAP_ASCENDANT_SPAWNERS.md) for the porting plan.

## Status

Core gameplay is ported and functional (`0.0.0-beta.5`): silk-touching spawners, spawner stat modification recipes, JEI/Jade compat, advancements, loot table, enchantment. Remaining work: QA pass for functional parity with the original, and final art (current textures are placeholders).

## Requirements

| Component | Version |
|---|---|
| Minecraft | 26.2 |
| NeoForge | 26.2.0.32-beta |
| Java | 21+ |
| Common Toolkit | required |
| Ascendant Equipment | optional for now — required once it ships a build |
| JEI | optional |
| Jade | optional |

## Installation

1. Install [NeoForge](https://neoforge.net/) for Minecraft 26.2.
2. Install Common Toolkit.
3. Download the mod jar and place it in your `mods/` folder.
